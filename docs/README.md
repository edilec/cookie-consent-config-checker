# Consent checker operator notes

Use a disposable fixture export that captures the full script-event sequence, exercises every mapped optional script at least once, and explicitly marks it complete. The event array is ordered evidence, not a reconstruction from wall-clock timestamps. Keep the policy and capture beside one another under an input root; use separate roots or runs for independent fixtures. A clean report says the exported sequence obeyed the declared technical policy. It does not establish that the browser capture was authentic, that all production pages behave the same way, or that any jurisdiction's consent law is satisfied.

The reporter reads only the two named files and emits no generated file. Its stable source roles refer to the two names passed at invocation. Never place real browsing histories, user IDs, or personal data in a fixture; the minimal schema intentionally contains no such fields.
